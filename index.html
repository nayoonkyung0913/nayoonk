스크롤 효과 사용법

아임웹에 라이브러리를 한 번 연결하세요. 다음 상품부터는 사진이나 문구의 HTML 태그에 data-aos 속성을 붙이면 화면에 들어올 때 움직입니다.

처음 한 번 설치

디자인 모드에서 상품 상세페이지의 코드 위젯에 아래 한 줄을 넣고 저장하세요. 적용한 상품을 미리보기에서 확인한 뒤 게시하세요.

<script defer src="https://nayoonkyung0913.github.io/nayoonk/imweb-effects.js"></script>

상품마다 효과 고르기

상품 상세설명의 HTML 코드 보기(</>)에서, 원하는 요소의 여는 태그에 아래 속성을 붙이세요.

<h2 data-aos="fade-up">우리 상품 이야기</h2>

fade-up

제목이 아래에서 서서히 올라옵니다.

data-aos="fade-up"

zoom-in

작게 보이던 상품 사진이 원래 크기로 커집니다.

data-aos="zoom-in"

fade-right

왼쪽에서 오른쪽으로 이동하며 나타납니다.

data-aos="fade-right"

flip-up

접힌 카드가 위로 펼쳐지듯 돌아옵니다.

data-aos="flip-up"

속도와 시작 시점 조절

아래 사진은 화면에 들어온 뒤 150ms를 기다렸다가 700ms 동안 확대됩니다. 사진 주소와 설명은 실제 상품에 맞게 바꾸세요.

<img src="상품사진.jpg" alt="상품 사진" data-aos="zoom-in" data-aos-delay="150" data-aos-duration="700">

카작 전용 갤러리

카작 갤러리를 사용하는 상세설명은 기존 article.kz-story에 data-imweb-fx="1" data-imweb-template="kazak"을 유지하세요.
