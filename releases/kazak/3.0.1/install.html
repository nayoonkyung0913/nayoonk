카작 3.0.1 아임웹 적용

3.0.0을 사용 중이라면

상품 상세설명을 HTML 코드 보기(</>)로 열고, 맨 바깥 요소의 버전 값만 3.0.1로 바꾼 뒤 저장하세요. 공통 로더가 해당 버전의 CSS와 JS를 불러옵니다.

<div data-kazak-version="3.0.1">

상세설명 영역이 화면 전체 너비로 펼쳐집니다. 상품 이미지·가격·구매 버튼 영역은 아임웹의 레이아웃 설정을 따릅니다.

수정해 둔 사진과 문구를 사용하려면 기존 본문에서 버전 값만 바꾸세요. 아래 전체 본문 복사는 새로 설치할 때 사용할 기본 템플릿입니다.

1. 공통 상품 상세페이지의 코드 위젯

디자인 모드 → 상품 상세페이지 → 코드 위젯에 아래 한 줄을 넣고 저장하세요. 이 버전 로더는 사이트에 한 번만 설치합니다.

<script defer src="https://nayoonkyung0913.github.io/nayoonk/releases/loader/1.0.0/kazak-loader.js"></script>

2. 카작 상품의 상세설명

적용할 상품 편집 → 상세설명 → HTML 코드 보기(</>)에서 아래 본문을 붙여넣고 저장하세요. 사진과 문구, 버전 표시가 모두 포함돼 있어요.

본문 원문 열기

미리보기에서 주황색 첫 화면과 다섯 맛 탭 전환을 확인한 뒤 게시하세요.
