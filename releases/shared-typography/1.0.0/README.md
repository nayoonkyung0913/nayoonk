# MINES shared Pretendard 1.0.0

카작·이지마요·크런치벗·쭉짜먹는 땅콩버터·웨츠드롭의 HTML 텍스트를 Pretendard로 통일하는 공통 CSS입니다.

- 기존 상품 CSS/JS는 유지하고, 이 CSS 링크 한 줄을 공통 상세페이지 코드 끝에 추가합니다.
- 다섯 상품의 data-version 속성 내부에만 적용하며 사이트 메뉴·구매 영역 등은 변경하지 않습니다.
- 영문 필기체·한글 명조를 포함해 모든 텍스트의 글꼴을 통일합니다. 이미지 자체에 포함된 로고·패키지 글자는 그대로입니다.
- 띠배너는 카작 기준 clamp(30px,5vw,60px), 굵기800, 줄높이1.6, 자간-.04em입니다. 아임웹 모바일 14px!important 규칙보다 우선합니다.
- 공통 폰트 파일은 기존 이지마요 배포본의 Pretendard Variable WOFF2를 사용합니다.
- 상품별 HTML은 공통 서체가 적용된 공개 미리보기이며, 기존 개별 상품 HTML을 교체할 필요는 없습니다.
