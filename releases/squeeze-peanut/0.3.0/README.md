# 쭉짜먹는땅콩버터 상세페이지 0.3.0

- body.html / body.txt: 아임웹 상품 상세설명의 코드 모드에 붙여 넣는 본문.
- peanut.css: 공통 스타일과 제품별 보정을 합친 배포 CSS.
- peanut.js: data-squeeze-peanut-version="0.3.0" 본문 전용 인터랙션.
- fonts/: 공통 스타일에서 사용하는 폰트.
- assets.json: 카페24 이미지 18개 URL 및 SHA-256.
- index.html: 같은 배포 파일과 카페24 이미지를 사용하는 미리보기.

다른 제품의 본문이나 스타일은 수정하지 않습니다. 실제 아임웹 상품 등록·저장은 별도로 진행합니다.
