# WETZ DROP 1.2.4

카작 3.0.2 / 이지마요 0.5.7의 섹션 배치와 스크롤 동작을 바탕으로 만든 아임웹 상세페이지.

- 이미지: 카페24 /web/upload/wetz-drop/ 원본 PNG 24개 및 물방울 애니메이션용 보정 사진 1개, 투명 원물 이미지 6개, 특징 설명용 누끼 이미지 2개. 공개 파일 SHA-256 검증.
- 1.2.4: 맨 위 메인 배경을 순백색(#fff)으로 변경. 무설탕 카드에는 맑은 물컵+보틀, 휴대성 카드에는 작은 파우치에서 보틀을 꺼내는 손을 투명 PNG로 적용.
- 1.2.3: 일상 활용 섹션의 사진 스크롤 회전 제거. 상단 How to enjoy와 카드 영문을 카작과 동일한 Allura로 통일. 20px 간격의 실버 도트 배경 복원.
- 1.2.2: 상단 MINES / DAILY WATER, YOUR WAY. 문구 제거. 첫 섹션 배경을 푸른기 적은 실버 그레이로 변경. 작은 한 병 특징 섹션의 두 생활 사진을 기존 제품 보틀 누끼 구성으로 교체.
- 맛 선택 섹션의 배경은 원본 패키지 동그라미에서 추출한 맛별 색상·그라데이션을 사용하며, 명도에 따라 글자와 선택 탭 색도 변경. 50g · 0kcal · 무설탕 한 줄 삭제.
- 1.2.1: 향을 표현한 연출 이미지 안내 문구 삭제. 맛 섹션 모바일 배치·폭·간격·탭 모양을 카작 3.0.2와 통일. 700px 이하에서는 제품과 설명을 세로로 배치하며 원물과 추가 용량 줄은 숨김.
- 1.2.0: 음용 안내를 2–3방울로 변경하고 6가지 맛을 과일·허브 원물 이미지로 표현. 카작과 같은 세로 상품정보 아코디언, 공통 보관/섭취 안내. 하단 로고 섹션과 움직임 멈추기 버튼 삭제. 스크롤에 따라 물방울이 스포이드에서 컵으로 낙하하고 수면에 잔물결이 생김.
- 패키지 박스: 기존 410 × 672 기준을 615 × 672로 변경. 폭 1.5배, 높이 유지. 원본 병과 인쇄 영역은 CSS로 분리해 인쇄 비율 유지.
- 모든 CSS, JavaScript는 data-wetz-drop-version="1.2.4"에 한정.
- index.html: 공개 미리보기. body.txt: 아임웹 개별 상품 상세설명 코드 모드에 붙여넣는 본문.
- CSS/JS는 공통 상세페이지에 1회 추가. 기존 웨츠드롭 코드는 교체하고 다른 제품 코드는 유지.
- PC 1440 × 900, 모바일 390 × 844 / 320 × 568에서 가로 넘침, 이미지, 탭, 상품정보 확인.
- 메인 스크롤 정방향/역방향, 사용법 마지막 카드, 키보드 탭 이동, 모션 축소 모드 확인.
- 영양정보는 2026-01-12 표시사항 PDF 기준. 사용법은 2026-11-19 사용자 수정 요청에 따라 2–3방울로 반영. 수치가 다른 연출 이미지 17/26/29/30은 미사용.
